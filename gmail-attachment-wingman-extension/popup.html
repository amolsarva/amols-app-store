Attachment Wingman

Build or reopen your Gmail attachment extractor.

1 · Open Apps Script

Use the Google account / Chrome profile you want. This extension does not read Gmail.

2 · Paste these files

Code.gs
Index.html

3 · Deploy + run checklist

  1. In Apps Script, name the project Gmail Attachment Extractor.
  2. Paste Code.gs.
  3. Click + → HTML, name it Index, paste Index.html.
  4. Click Deploy → New deployment → Web app.
  5. Set Execute as: Me.
  6. Set Who has access: Only myself.
  7. Click Deploy, authorize, then open the web app URL.
  8. Run a query like has:attachment newer_than:7d.
