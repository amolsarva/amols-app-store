# Install Meet Tab Sidecar

## Load the unpacked extension

1. Open Chrome.
2. Go to `chrome://extensions`.
3. Enable Developer mode.
4. Click Load unpacked.
5. Select:

```text
/Users/MrAnonymous/Documents/root/mac-scripts/meet-tab-sidecar-extension
```

## Use it

1. Click the Meet Tab Sidecar extension button.
2. Set your Meet URL if you have one.
3. Set the work tab URL, spoken intro, and audio URL.
4. Click Open Meet.
5. Click Open Sidecar.
6. In Google Meet, share the Sidecar tab with tab audio enabled.

## Install from zip

The packaged zip is:

```text
/Users/MrAnonymous/Documents/root/mac-scripts/downloads/meet-tab-sidecar-extension.zip
```

Unzip it, then load the unzipped folder with Chrome's Load unpacked button.
