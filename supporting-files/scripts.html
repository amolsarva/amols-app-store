How to get going

You don't need to be a programmer. Everything here is one of three types — find the kind of tool you want, and follow the matching path.

🌐  Web apps

Just click and use

Tools like DadsBot and OpenSnoRE open right in your browser. Hit Try on the card — nothing to download or install.

No setup
🧩  Chrome extensions

Add to Chrome once

Open chrome://extensions, flip on Developer mode (top-right), click Load unpacked, and pick the extension's folder. It then lives in your toolbar.

A little setup
🖥️  Mac scripts

Download & double-click

Hit Get, then double-click the downloaded .command file — Terminal opens and runs it. Every cleanup tool shows you the mess and asks before deleting a thing.

A little setup
💡 First time opening a downloaded Mac script, macOS may warn it's from an "unidentified developer." Right-click the file → Open → Open once, and you're set. Want the full collection and per-tool instructions? See the GitHub shelf.
